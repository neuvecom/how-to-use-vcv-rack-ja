## 2. アイデアのレビュー

### 実現可能性

十分に実現可能です。VCV Rack 2 は無料版（Free）があり Windows / macOS / Linux で動くため、読者が追体験しやすい教材になります。AmbientModules は VCV Library に公開されているプラグインで（[library.vcvrack.com/AmbientModules](https://library.vcvrack.com/AmbientModules)、6 モジュール収録）、無料版 Rack からも導入できる想定です（※ 価格・ライセンスは要確認）。

記事部分は静的サイトで作り、**ログインと受講の進捗管理** だけを Firebase（Authentication / Cloud Firestore）でブラウザ側から実装します（2026-10-07 要望追加）。専用サーバーは不要です。

## 3. 基本設計・アーキテクチャ提案

### 方針：Markdown で書く静的サイト ＋ Firebase（Hosting / Auth / Firestore）

```
記事 (Markdown / MDX) ──▶ 静的サイトジェネレーター ──▶ GitHub Actions ──▶ Firebase Hosting
画像・音源・.vcv ─────┘                         （main マージで自動デプロイ / PR でプレビュー）
```

| レイヤー | 提案 | 理由 |
|---|---|---|
| サイト生成 | **Astro + Starlight**（ドキュメントサイト用テーマ） | Markdown で書ける、サイドバー・検索・日本語対応が標準、ハウツー/チュートリアル形式に向く |
| ホスティング | **Firebase Hosting**（idea.md の想定どおり） | 無料枠で十分、PR ごとのプレビュー URL を GitHub Actions で出せる |
| 認証 | **Firebase Authentication** | Google ログイン・メールリンク。ブラウザ側 SDK で完結 |
| DB | **Cloud Firestore** | `users/{uid}/progress/{lessonId}` に完了日時を保存。セキュリティルールで本人のみ読み書き可 |
| CI/CD | GitHub Actions（`FirebaseExtended/action-hosting-deploy`） | main → 本番、PR → プレビューチャンネル |
| 素材 | `public/` 配下に画像・音源・パッチを格納 | 記事からの相対参照で管理しやすい |

代替案：
- **VitePress**（より軽量、Vue ベース）。カスタマイズが少ないならこちらでも可。
- **GitHub Pages**（Firebase の設定・課金アカウントが不要で最も手軽）。PR プレビューは別途工夫が必要。

### ログイン・進捗管理の仕組み（案）

- ヘッダーにログインボタン、各レッスン末尾に「このレッスンを完了」ボタンを置く（Astro のクライアント側コンポーネント）
- ログイン時のみ Firestore に記録。未ログインでも記事は読める
- 「マイページ」でコースごとの進捗率（例: ワークショップ 3/5 完了）を表示
- Firestore のデータ構造
  ```
  users/{uid}                       # 表示名・作成日時
  users/{uid}/progress/{lessonId}   # completedAt
  ```
- セキュリティルール：`request.auth.uid == uid` のときだけ読み書き可
- Firebase の無料枠（Spark プラン）で十分に収まる想定

## 4. コンテンツ構成（案）

### A. はじめに（超入門）
1. モジュラーシンセって何？（音の高さ・音色・音量の 3 要素で考える）
2. 「電圧で音を操る」とは（CV / Gate を日常の例えで）

### B. 基本編：VCV Rack の使い方
1. インストールと初期設定（アカウント作成、オーディオ設定）
2. 画面の見方と基本操作（モジュール追加、ケーブル、ノブ、保存）
3. 最初の音を出す（VCO → VCA → Audio）
4. 音を動かす（LFO・エンベロープ）
5. 音色を削る（VCF）
6. メロディを鳴らす（シーケンサー / MIDI キーボード）
7. エフェクトで空間を作る（ディレイ・リバーブ）
8. プラグインを追加する（VCV Library の使い方）

### C. モジュール解説（一般人向け）
- まず **VCV 標準（Fundamental）** の主要モジュールから。1 モジュール 1 ページ、
  「何をするもの？ / つまみの意味 / 試してみよう（パッチ＋音）」の固定フォーマット。

### D. ワークショップ：Lunar シリーズでアンビエント曲を作る
1. Lunar シリーズの導入と全体像
2. ドローン（持続音）を作る
3. ゆらぎ・変化をつける
4. 空間系で広げる
5. 1 曲にまとめて録音する
- ※ 各回の内容は収録モジュールを実機で確認後に確定

### E. 用語集
- VCO / VCF / VCA / LFO / ENV / CV / Gate / Trigger などを平易に
