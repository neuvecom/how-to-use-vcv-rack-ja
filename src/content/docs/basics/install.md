この記事では、VCV Rack をパソコンにインストールして起動し、音が出せる状態に設定するところまで進めます。

- **所要時間**: 約 15 分
- **前提**: なし（この記事から始めて大丈夫です）
- **必要なもの**: パソコン（Windows / Mac / Linux）、ヘッドホンかスピーカー、メールアドレス

## VCV Rack とは

VCV Rack は、**モジュラーシンセサイザー** をパソコンの画面上で再現する無料のソフトウェアです。モジュラーシンセサイザーとは、「音を作る部品」「音色を変える部品」「音量を変える部品」などの **モジュール**（1 つの機能を持った部品）を、ケーブルでつないで音を作る楽器です。本物をそろえると数十万円かかりますが、VCV Rack なら無料で同じ考え方を学べます。

VCV Rack には次の 2 つの版があります。このサイトでは **無料の Free 版** を使います。

| 版 | 価格 | 違い |
|---|---|---|
| VCV Rack 2 Free | 無料 | 単体のソフトとして動く。このサイトの内容はすべてこれで試せます |
| VCV Rack 2 Pro | 有料 | DAW（音楽制作ソフト）の中にプラグインとして組み込める |

## 1. パソコンが対応しているか確認する

公式サイトに書かれている動作環境は次のとおりです。

| 項目 | 必要なもの |
|---|---|
| OS | Windows 7 以降、macOS 10.9 以降、Linux（Ubuntu 16.04 以降） |
| CPU | 2011 年以降の 64 ビットの Intel / AMD 製 CPU、または Apple M1 以降 |
| メモリ | 1 GB 以上 |
| ディスクの空き | 1 GB 以上 |
| グラフィック | 2013 年以降の独立したグラフィックカードが推奨（パソコン内蔵のグラフィックでも動くことが多いですが、動きが重くなる場合があります） |

ここ数年以内に買ったパソコンであれば、ほとんどの場合そのまま動きます。

## 2. VCV のアカウントを作る

VCV Rack に追加のモジュールを入れるには、VCV のアカウント（無料）が必要です。先に作っておきましょう。

1. [VCV の公式サイト](https://vcvrack.com/) を開きます。
2. 画面右上の「Register / Log in」をクリックします。
3. メールアドレスとパスワードを入力して登録します。

<!-- 画像: vcvrack.com の右上にある「Register / Log in」 -->

## 3. ダウンロードしてインストールする

1. [VCV Rack のページ](https://vcvrack.com/Rack) を開き、「Rack 2 Free」のダウンロードボタンから、自分の OS（Windows / Mac / Linux）のものを選んでダウンロードします。
2. ダウンロードしたファイルを開いて、インストールします。

<!-- 画像: ダウンロードページで OS を選ぶところ -->

| OS | インストールのしかた |
|---|---|
| Windows | ダウンロードしたインストーラーを実行し、画面の指示に従います。終わったらデスクトップかスタートメニューから起動します |
| Mac | ダウンロードしたインストーラーをダブルクリックし、画面の指示に従います。終わったら「アプリケーション」フォルダーから起動します |
| Linux | ZIP ファイルを展開し、中の `Rack` を実行します（`zenity` が必要です） |

## 4. 起動して画面を確認する

VCV Rack を起動すると、最初から **2 つのモジュールが置かれた画面** が表示されます。これは「テンプレート」と呼ばれる最初の状態です。

- **Audio**: パソコンのスピーカーやヘッドホンに音を送るモジュール
- **MIDI to CV**: MIDI キーボード（パソコンにつなぐ鍵盤）の信号を、モジュールが扱える信号に変えるモジュール

<!-- 画像: 起動直後のテンプレート。Audio と MIDI to CV が並んでいる -->

画面の黒っぽい部分が **ラック**（モジュールを並べる棚）です。ここにモジュールを追加し、ケーブルでつないで音を作っていきます。

## 5. 音の出口を設定する

VCV Rack の音をスピーカーやヘッドホンから出すために、**Audio** モジュールの設定をします。

:::caution
最初に、パソコンの音量を **小さめ** にしておいてください。モジュラーシンセは、つなぎ方によって急に大きな音が出ることがあります。特にヘッドホンを使うときは注意しましょう。
:::

1. **Audio** モジュールの上部にある、黒い表示部分をクリックします。
2. 表示されたメニューから **ドライバー**（音を出す仕組み）を選びます。
   - Windows: まずは「WASAPI」を選ぶのがおすすめです
   - Mac: 「Core Audio」を選びます
3. もう一度表示部分をクリックし、音を出したい **デバイス**（スピーカーやヘッドホン）を選びます。

<!-- 画像: Audio モジュールの表示部分をクリックしてドライバーを選ぶメニュー -->

これで、VCV Rack から音を出す準備ができました。実際に音を出すのは次の記事で行います。

:::tip[ポイント]
音がとぎれる、プツプツとノイズが入るときは、同じメニューで「Block size」を大きい値（例: 512 や 1024）にすると改善することがあります。
:::

## 6. VCV Rack にログインする

手順 2 で作ったアカウントで、VCV Rack にログインしておきます。ログインすると、あとで追加のモジュール（プラグイン）を入れられるようになります。

1. 画面上部のメニューバーから「Library」を開きます。
2. メールアドレスとパスワードを入力して、ログインします。

<!-- 画像: Library メニューのログイン欄 -->

追加モジュールの入れ方は、別の記事で説明します。

## 7. パッチを保存してみる

モジュールとケーブルのつなぎ方の組み合わせを **パッチ** と呼びます。パッチはファイルとして保存でき、あとで続きから作業できます。

1. メニューバーの「File > Save as」を選びます。
2. 保存する場所と名前を決めて保存します。ファイルの拡張子は `.vcv` です。

2 回目からは「File > Save」（`Ctrl`+`S`、Mac は `Cmd`+`S`）で上書き保存できます。

## うまくいかないときは

### 音が出ない、デバイスが一覧に出てこない

ほかの音楽ソフトや動画サイトが音を使っていると、選べないことがあります。ほかのソフトを閉じてから、Audio モジュールでドライバーとデバイスを選び直してください。

### 画面が真っ黒、または起動してすぐ終了する

グラフィック（画面表示）の機能が足りない可能性があります。グラフィックドライバーを最新にしてから、もう一度起動してみてください。

### 設定ファイルの場所を知りたい

メニューの「Help > Open user folder」で、VCV Rack が設定や追加モジュールを保存しているフォルダーを開けます。

## まとめ

- VCV Rack 2 Free を公式サイトからダウンロードしてインストールしました。
- 「Audio」モジュールで、音を出すドライバーとデバイスを設定しました。
- パッチは「File > Save」で `.vcv` ファイルとして保存できます。

次は、モジュールを追加してケーブルをつなぎ、最初の音を出してみましょう（記事は準備中です）。

## 確認した環境

- VCV Rack 2 Free 2.6.6（手順は公式サイトとマニュアルの記載をもとに作成）
