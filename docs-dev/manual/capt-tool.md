# 画面ショットを作成するために、アプリのウインドウの大きさを修正

記事用のスクリーンショットを撮る前に、VCV Rack のウインドウを **毎回同じ位置・同じ大きさ** にそろえる方法です。大きさがそろっていると、記事ごとに画像の縮尺や見え方がばらつかず、読者が見比べやすくなります。

- **対象**: macOS（記事の画像を撮る人向け。サイトには載せない作業用の手順です）
- **所要時間**: 初回の設定に約 10 分、以降は 1 クリック

## 方法

追加の機材やアプリを購入することなく、macOS の純正の機能を使って実現できます。

1. 「スクリプトエディタ」で、ウインドウの位置と大きさを変える AppleScript を作ります。
2. 作ったスクリプトを、メニューバーの「スクリプトメニュー」から 1 クリックで実行できるようにします。

### スクリプトエディタ

1. スクリプトエディタを起動します。
   - Finder で「アプリケーション > ユーティリティ > スクリプトエディタ」を開く、または `Cmd`+`Space` の Spotlight で「スクリプトエディタ」と入力します。
2. 起動時にファイルを選ぶ画面が出たら、左下の「新規書類」をクリックします。
3. 以下のコードを入力します。

   ```applescript
   tell application "System Events"
       -- 対象にするアプリの名前を指定（例: Safari）
       tell process "VCV Rack 2 Free"
           -- 1番手前にあるウィンドウの [位置] と [サイズ] を指定
           set position of window 1 to {100, 100} -- 左上からの座標（X, Y）
           set size of window 1 to {1440, 900} -- ウィンドウの幅と高さ（横幅, 縦幅）
       end tell
   end tell
   ```

4. VCV Rack を起動しておきます。
5. スクリプトエディタのツールバーの「▶︎（実行）」ボタンをクリックするか、`Cmd`+`R` を押します。
6. 初回は許可を求めるダイアログが出ます。次の 2 つを許可します。
   - 「"スクリプトエディタ" から "System Events" を制御するアクセスを要求しています」→「OK」
   - アクセシビリティの許可 →「システム設定を開く」から「プライバシーとセキュリティ > アクセシビリティ」で「スクリプトエディタ」をオンにする
7. 許可したあと、もう一度実行します。VCV Rack のウインドウが画面左上から (100, 100) の位置に、幅 1440 × 高さ 900 の大きさで表示されれば成功です。
8. 「ファイル > 保存」（`Cmd`+`S`）で保存します。
   - 名前: `VCV Rack を 1440x900 にする` など、何をするかわかる名前
   - ファイルフォーマット: 「スクリプト」（拡張子 `.scpt`）
   - 保存場所はいったん「書類」などで構いません（次の節で移動します）

:::tip[ポイント]
大きさの数値は「ポイント」単位です。Retina ディスプレイの Mac では、撮った画像は 2 倍のピクセル数（1440 × 900 なら 2880 × 1800 ピクセル）になります。
:::

:::note
画面より大きなサイズを指定すると、画面に収まる大きさで止まります。また、フルスクリーン表示中のウインドウは大きさを変えられないので、先にフルスクリーンを解除してください。
:::

#### ※プロセスでアプリ名を確認する方法

`tell process "…"` には、macOS が認識している **プロセス名** を書きます。アプリのファイル名と違うことがあるので、うまく動かないときは次の手順で確認します。

1. 対象のアプリ（VCV Rack）を起動しておきます。
2. スクリプトエディタで新規書類を作り、次のコードを実行します。

   ```applescript
   tell application "System Events"
       get name of every process whose background only is false
   end tell
   ```

3. 画面下の「結果」欄に、いま起動している（Dock に表示される）アプリのプロセス名が一覧で表示されます。
   - 例: `{"Finder", "Safari", "スクリプトエディタ", "VCV Rack 2 Free"}`
4. 一覧の中から対象のアプリの名前をそのままコピーし、`tell process "…"` の部分に貼り付けます。

「結果」欄が見えないときは、「表示 > 結果を表示」を選びます。

同じ方法で、Safari など VCV Rack 以外のアプリのウインドウもそろえられます。

### メニューバーから実行できるようにする（スクリプトメニュー）

毎回スクリプトエディタを開かなくて済むよう、メニューバーの「スクリプトメニュー」に登録します。

#### メニューの有効化

1. スクリプトエディタで「スクリプトエディタ > 設定…」（macOS 12 以前は「環境設定…」）を開きます。
2. 「一般」タブの「メニューバーにスクリプトメニューを表示」にチェックを入れます。
3. メニューバーの右側に、巻物の形をしたスクリプトメニューのアイコンが表示されます。

#### スクリプトの移動

スクリプトメニューには、ユーザーのスクリプトフォルダー（`~/Library/Scripts/`）にあるスクリプトが表示されます。

1. メニューバーのスクリプトメニューから「ユーザスクリプトフォルダを開く」を選びます。Finder で `~/Library/Scripts/` が開きます。
   - フォルダーが無い場合は、Finder で「移動 > フォルダへ移動…」（`Cmd`+`Shift`+`G`）に `~/Library/Scripts/` と入力して開くか、作成します。
2. 前の節で保存した `.scpt` ファイルを、このフォルダーに移動します。

:::tip[ポイント]
`~/Library/Scripts/Applications/VCV Rack 2 Free/` のように、`Applications` の下にアプリ名のフォルダーを作って入れると、**そのアプリが手前にあるときだけ** メニューに表示されます。スクリプトが増えてきたら使い分けると便利です。
:::

#### 動作の確認

1. VCV Rack を起動し、ウインドウの大きさを適当に変えておきます。
2. メニューバーのスクリプトメニューから、保存したスクリプト名を選びます。
3. VCV Rack のウインドウが指定した位置と大きさに変われば完了です。

初回はスクリプトメニューからの実行についても、アクセシビリティや「System Events」の制御の許可を求められることがあります。その場合は前の節と同じように許可してください。

## スクリーンショットの撮り方

ウインドウをそろえたら、ウインドウ単位で撮影します。

1. `Cmd`+`Shift`+`4` を押し、続けて `Space` を押します。カーソルがカメラの形に変わります。
2. VCV Rack のウインドウにカーソルを合わせてクリックします。
   - `Option` を押しながらクリックすると、ウインドウの影なしで撮れます。
3. デスクトップに画像が保存されます。

撮った画像は、[writing-guide.md](./writing-guide.md) の「4. 画像・音・パッチファイル」のルールに従って、`public/images/<記事のパス>/` に番号付きのファイル名で置きます。

## うまくいかないときは

### 「アクセシビリティ機能を使用したアクセスが許可されていません」と表示される

「システム設定 > プライバシーとセキュリティ > アクセシビリティ」で、実行しているアプリ（スクリプトエディタ、またはスクリプトメニューから実行した場合は表示された項目）がオンになっているか確認してください。すでにオンなのに動かない場合は、いったんオフにしてからオンに戻します。

### 「プロセスが見つかりません」のようなエラーになる

- VCV Rack が起動しているか確認してください。
- `tell process "…"` の名前が正しいか、「※プロセスでアプリ名を確認する方法」で確認してください。VCV Rack Pro など、エディションが違うと名前も変わります。

### ウインドウが指定した大きさにならない

- フルスクリーン表示になっていないか確認してください。
- 指定したサイズが画面より大きいと、画面に収まる大きさで止まります。外部ディスプレイなど大きな画面で撮るか、サイズを小さくしてください。

## 想定している環境

- macOS 13 以降（メニュー名は macOS 15 の表記）
- VCV Rack 2 Free 2.6.6
