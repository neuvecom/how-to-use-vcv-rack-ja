# 2026-10-29 作業ログ

## neuve.com への移行と全コース共通ログインへの切り替え

### 実施内容
- 全コース共通のログイン・進捗同期（ポータル neuve.com/learn/）に合わせ、公開先を Firebase Hosting（web.app）から GitHub Pages（neuve.com/how-to-use-vcv-rack-ja/）へ移した。他コースと同じドメインになるため、1 回のログインで全コースに反映される
- 独自のログイン・マイページ・完了ボタンを、ポータルが配信する共通キット（`<neuve-auth>`・`<neuve-lesson-done>`）に置き換えた
- Firestore の保存先を全コース共通の `users/{uid}/courses/{courseId}/lessons/{lessonId}` に変更し、セキュリティルールを全コース用に書き換えた

### 変更
- `astro.config.mjs`: `site` を `https://neuve.com`、`base` を `/how-to-use-vcv-rack-ja` に変更。共通キットを全ページの head で読み込む
- `src/components/AuthStatus.astro`: `<neuve-auth>` に置き換え。旧形式の進捗データ（`users/{uid}/progress`）をログイン時に新形式へ移す処理を追加
- `src/components/LessonFooter.astro`: 完了ボタンを `<neuve-lesson-done course="vcv-rack">` に置き換え
- `src/pages/course.json.ts`: ポータルのマイページが読むレッスン一覧を追加
- `src/pages/login/`・`src/pages/mypage/`: ポータルへの転送ページに置き換え（`src/pages/login.astro`・`mypage.astro`・`src/lib/firebase.ts` は削除、`firebase` パッケージも削除）
- `firestore.rules`: 全コース共通のルールに書き換え（旧パスは読み取り・削除のみ許可）
- `firebase.json`・`firebase-redirect/`: Firebase Hosting を旧 URL からの 301 転送専用に変更
- ワークフロー: `deploy.yml`（GitHub Pages）と `ci.yml`（PR のビルド確認）を追加、`firebase-hosting-merge.yml` を転送設定の反映専用に変更、`firebase-hosting-pull-request.yml` を削除
- `README.md`: 公開先・ログインと進捗管理の説明を更新

### 検証
- `npm run build` 成功（`dist/course.json` に基本編のレッスンが出力されることを確認）
- `astro preview` で、ヘッダーに「ログイン」、レッスン末尾に完了ボタンの案内が表示されることを確認（共通キットはローカルのファイルに差し替えて表示）
- Firestore エミュレーターで新ルールを 19 ケース検証（本人の読み書き・他人や未ログインの拒否・未知のコース・余分なフィールド・未来の時刻の拒否・端末保存値 local の長さと型・旧データの移行バッチの成功）

### 後方互換性
- 旧 URL（web.app）は 301 で新 URL へ転送されるので、既存のリンクやブックマークは使える
- ログイン状態はドメインが変わるため 1 回だけログインし直しが必要。進捗データは同じ Firebase に残り、ログイン時に新形式へ自動で移る
- マージ前に、GitHub Pages の有効化（Settings → Pages → GitHub Actions）と、Firestore ルールの反映が必要
