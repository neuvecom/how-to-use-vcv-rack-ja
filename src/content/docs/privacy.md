【要記入：運営者名】（以下「運営者」）は、ウェブサイト「ゼロからの VCV Rack」（以下「本サイト」）における利用者の個人情報を、以下のとおり取り扱います。

## 1. 取得する情報

本サイトは、記事を読むだけであればログインは不要で、個人を特定できる情報は取得しません。ログイン機能を利用した場合に限り、次の情報を取得します。

| 情報 | 取得するタイミング |
| --- | --- |
| メールアドレス | Google アカウントまたはメールアドレスでログインしたとき |
| 表示名・プロフィール画像の URL | Google アカウントでログインしたとき（Google から提供される範囲） |
| ユーザー ID（ログインサービスが自動で割り当てる識別子） | ログインしたとき |
| 学習の進捗（完了にしたレッスンと、その日時） | レッスンの「完了」ボタンを押したとき |

パスワードは取得しません。メールアドレスでのログインは、届いたリンクを開く方式です。

## 2. 利用目的

取得した情報は、次の目的にのみ利用します。

- ログイン状態を保ち、利用者ごとに学習の進捗を記録・表示するため
- 本サイトの不正利用を防止するため
- お問い合わせへの対応のため

## 3. 外部サービスの利用

本サイトは、ログインとデータの保存に Google LLC が提供する **Firebase**（Firebase Authentication、Cloud Firestore、Firebase Hosting）を利用しています。取得した情報は Firebase のサーバーに保存され、Google のプライバシーポリシーに従って管理されます。

- [Firebase におけるプライバシーとセキュリティ](https://firebase.google.com/support/privacy)
- [Google プライバシーポリシー](https://policies.google.com/privacy?hl=ja)

また、各ページ下部の支援バナーは Ko-fi（Ko-fi Labs Limited）への外部リンクで、バナーの表示にはファイル配信サービス jsDelivr を利用しています。バナーを表示する際、閲覧者の IP アドレスなどの接続情報が jsDelivr に送られます。

学習の進捗データは、ログインしている本人だけが読み書きできるよう、アクセスを制限しています。

## 4. ブラウザへの保存（Cookie など）

ログイン状態を保つため、Firebase Authentication がブラウザのストレージ（IndexedDB など）にログイン情報を保存します。また、メールアドレスでログインする際、確認のためにメールアドレスを一時的にブラウザに保存します。現在、本サイトはアクセス解析ツールや広告配信を利用していません。

## 5. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません（上記「外部サービスの利用」に記載したサービスへの保存を除きます）。

## 6. 情報の削除

ログアウトするだけではデータは削除されません。アカウントと学習進捗の削除を希望される場合は、下記のお問い合わせ先までご連絡ください。本人確認のうえ、削除します。完了にしたレッスンは、各レッスンの「完了を取り消す」ボタンでいつでも個別に取り消せます。

## 7. 外部リンク

本サイトには、YouTube や VCV Library など外部サイトへのリンクや埋め込みが含まれます。外部サイトでの情報の取り扱いは、各サイトのプライバシーポリシーをご確認ください。

## 8. ポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。変更後のポリシーは、本ページに掲載した時点から効力を生じます。

本ポリシーに関するお問い合わせ、データの削除依頼は、【要記入：連絡先（メールアドレスやお問い合わせフォームの URL など）】までご連絡ください。
